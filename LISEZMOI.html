Luisart · mettre l’application en ligne

Ce dossier contient la vraie application Luisart, indépendante de Claude : comptes, messages entre membres, photos, appels vidéo avec caméra et micro, installation sur le téléphone.

Contenu du dossier

  • index.html : l’application.
  • firebase-config.js : la seule chose à remplir (vos clés Firebase).
  • luisart-firebase.js : le branchement à Firebase (ne pas modifier).
  • import.html : copie vos œuvres et votre profil de la bêta.
  • firestore.rules, storage.rules : la sécurité de la base.
  • manifest.webmanifest, sw.js, icons/ : installation sur le téléphone.

Étape 1 · Créer la base Firebase (gratuit)

  1. Ouvrez console.firebase.google.com avec votre compte Google, puis « Créer un projet » nommé luisart. Google Analytics peut être désactivé.
  2. Dans le projet, touchez l’icône Web </> pour ajouter une application, nom « Luisart ». Copiez le bloc firebaseConfig qui s’affiche.
  3. Authentication › Commencer › Méthodes de connexion : activez Anonyme et Google.
  4. Firestore Database › Créer une base de données › mode production, région la plus proche (Europe). Puis onglet Règles : remplacez tout par le contenu de firestore.rules et touchez Publier.
Photos et documents joints : les photos des œuvres fonctionnent déjà sans rien de plus. Pour les documents (PDF…) envoyés dans les messages, il faut activer Storage, qui demande d’ajouter une carte bancaire au projet (offre « Blaze » ; les premiers 5 Go restent gratuits). À faire plus tard.

Étape 2 · Héberger l’application

Option simple depuis le téléphone, GitHub Pages (gratuit)

  1. Créez un compte sur github.com, puis un dépôt public vide nommé luisart.
  2. Envoyez le nom du dépôt à Claude : il y dépose tous les fichiers. Sinon : « Add file › Upload files » et ajoutez le contenu de ce dossier.
  3. Dans le dépôt : Settings › Pages › Branch main › Save. Votre adresse sera https://VOTRE-PSEUDO.github.io/luisart/.
  4. Dans Firebase : Authentication › Paramètres › Domaines autorisés › ajoutez VOTRE-PSEUDO.github.io.

Étape 3 · Remplir la configuration

Collez les valeurs copiées à l’étape 1 dans firebase-config.js (sur GitHub : ouvrir le fichier › crayon › Commit). Vous pouvez aussi simplement envoyer le bloc firebaseConfig à Claude, qui le remplit pour vous. Ces clés ne sont pas secrètes : la sécurité vient des règles.

Étape 4 · Importer vos données de la bêta

  1. Ouvrez https://VOTRE-PSEUDO.github.io/luisart/import.html.
  2. « Me connecter avec Google » avec amourdvine@gmail.com (le compte administrateur).
  3. « Importer les données ». Vos œuvres, votre profil, les actualités et les expositions sont copiés.

Étape 5 · Installer et partager

  • Android (Chrome) : ouvrez l’adresse › menu ⋮ › « Installer l’application ».
  • iPhone (Safari) : bouton Partager › « Sur l’écran d’accueil ».
  • Partagez l’adresse à vos artistes : chacun crée son compte et peut se connecter avec Google pour le retrouver sur tous ses appareils.

Ensuite

  • Play Store : pwabuilder.com transforme l’adresse en application Android (compte développeur Google : 25 $ une fois).
  • App Store : compte développeur Apple (99 $ par an).
  • Nom de domaine (luisart.ci, luisart.art…) : à relier à GitHub Pages ou Firebase Hosting.
  • Paiements Mobile Money : compte marchand CinetPay ou PayDunya.
  • Notifications : Firebase Cloud Messaging, à brancher dans une prochaine version.

Votre administrateur est défini par l’adresse amourdvine@gmail.com dans firebase-config.js et firestore.rules. Pour ajouter un autre administrateur, ajoutez son adresse aux deux endroits.
